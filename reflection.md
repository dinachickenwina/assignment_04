# Reflection

In this assignment I learned how a payroll pipeline works in three steps: cleaning, merging, and calculating pay. For cleaning, parse_hours turns messy text like "38h 30m" or "45m" into a float, and unreadable values like "forty" get coerced to 0.0 so one bad cell doesn't crash payroll. I used Series.apply to add hours_worked as a new column, and the original hours column stays next to it, which is data lineage. For merging, the timesheet and the roster have different grain, so I used a left merge with the timesheet on the left. That keeps every timesheet row, and an unknown ID like E099 gets NaN for the rate instead of being silently dropped, which an inner merge would have done. For calculating pay, calc_gross_pay pays time-and-a-half only for hours over 40, and a NaN rate pays 0.0, so I check it with pd.isna(). classify_pay then labels those rows "unmatched". I'm still confused about when to use row apply with axis=1 instead of Series.apply, so next I will rewrite add_gross_pay from memory and test it on timesheet_test.csv, where the total should be $4,133.72.
