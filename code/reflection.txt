The clearest thing I learned was how the grain of each file determines the merge. The roster has one row per employee, while the timesheet has one row per employee-week, so a left merge with the timesheet on the left keeps every person who worked. An unknown ID such as E099 receives NaN roster values instead of disappearing in an inner merge. Keeping those original values beside the cleaned and calculated columns also preserves data lineage through the pipeline.

The part I still find challenging is choosing between Series.apply and row apply with axis=1. Series.apply gives an element function one value at a time, while the gross-pay calculation needs both hours_worked and hourly_rate_usd from the same row.
